# 내버스시간표 (`bus`)

정류장마다 **내가 붙인 이름**과 **시간표 사진**을 한곳에 저장합니다.  
등록 시 기기 안에서 **자동 최적화**(밝기·대비·선명도) 후 저장합니다 (클라우드 AI 없음).  
확인할 때 사진을 누르면 **전체 화면 확대**, 「더 크게」, 손가락으로 밀어 세부 확인이 됩니다.

## 로컬 실행

`serve.cmd` → `dev-ports.json` 의 포트(기본 5176).

## 배포

Vercel 등 정적 호스트에 `bus` 폴더를 루트로 배포하면 됩니다. (`bus.uxpwa.com` 등)

`create-github-repo.cmd` → `deploy-github.cmd`
